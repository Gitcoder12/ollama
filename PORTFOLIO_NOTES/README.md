# Portfolio Notes — Ollama Fork

## In plain language

Ollama is a tool for running and serving language models locally or through its supported hosted options.

## Technical context

This repository is a fork of the upstream Ollama project. Upstream maintains its runtime, model distribution and platform installers. Local portfolio work should focus on reproducible model/runtime experiments, platform compatibility and focused upstream fixes while preserving upstream README, contributor guidance, licence and AGENTS.md.

## Provenance

This repository is a fork of [ollama/ollama](https://github.com/ollama/ollama). Upstream remains authoritative for the runtime, documentation, licences, releases and contribution rules. This folder contains only local portfolio notes.

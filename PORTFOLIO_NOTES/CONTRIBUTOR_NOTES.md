# Contributor Notes — Ollama Fork

This repository is a fork of ollama/ollama. Follow upstream CONTRIBUTING.md and applicable AGENTS.md instructions.

1. Preserve upstream README, licence, release and platform installation guidance.
2. Keep portfolio experiments and local notes under PORTFOLIO_NOTES/ or another clearly separate path.
3. For runtime bugs, pin the exact version/model and produce a minimal reproduction.
4. Test on the stated OS/hardware and include logs with secrets removed.
5. Do not modify model manifests or installers without a scoped reason and tests.
6. Submit upstream fixes to the original project when appropriate and report PR status accurately.
